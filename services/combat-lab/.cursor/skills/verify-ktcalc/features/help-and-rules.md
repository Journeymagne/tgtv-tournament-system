# Help and rules

Observable end state: `/help` shows the `h1` `How KT Calc works` and a link the user can follow into a rules doc. `/rules/combat` finishes loading and shows the markdown heading `Kill Team 2024 Combat Rules`, not `Loading…` and not `Could not load this document`.

## Sub-features

- Help index at `/help` with two panels: `Deep-dive notes` and `Game rules reference`.
- Note pages: `/notes/lethal-relentless`, `/notes/mystic-scry-buff`, `/notes/punishing`. Each has its own `h1` (the lethal page's heading starts `Lethal + Relentless`).
- Rules pages, fetched from `public/rules/*.md` (generated by `npm run copy-rules` on start): `/rules/combat`, `/rules/fight`, `/rules/weapon`, `/rules/cover-saves`, `/rules/weapon-balance`, `/rules/retained-vs-modified`.

## How to get to it (user POV)

The header link text is `How it works` (`a.AppHeader-help`). It opens `/help` in a new tab (`target="_blank"`). From help, follow a doc link such as `Combat rules — defense & the shooting save sequence`. The rules page has `← Back to How it works`. Notes linked from help use `← Back to calculator` on the note pages that link home.

## Driving it with the browser helper

1. Click `a.AppHeader-help`. Because of `target="_blank"`, follow the new tab (or open `http://127.0.0.1:$VERIFY_PORT/help` in that tab). Do not stay on the calculator tab and claim help loaded.
2. Wait for `h1` `How KT Calc works`.
3. Click the link `Combat rules — defense & the shooting save sequence` (it points at `/rules/combat`).
4. Wait until the text `Kill Team 2024 Combat Rules` is visible. The status line must not be `Loading…` and must not contain `Could not load this document`.
5. Click `← Back to How it works` and confirm the help `h1` is back.

## Gotchas

- Rules markdown is not in git under `public/rules/`. If launch was skipped and that directory is missing, the rules page shows `Could not load this document` after `Loading…`. That is a failed launch, not a content bug. `launch.sh` runs `prestart`, which copies the files.
- The header help link does not navigate the current tab. A driver that only watches the original tab will still see the calculator.
- Help and rules hide the share buttons and do not highlight Shoot or Fight (`onCalculator` is false for `/help`, `/notes`, and `/rules`).
