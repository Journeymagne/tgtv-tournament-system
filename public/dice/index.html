Локальная ссылка работает на этом компьютере, пока запущен компаньон.

Как импортировать кубик
  1. Создай ссылку и скопируй её.
  2. На блоке KT Studio Importer нажми IMPORT TEAM и вставь ссылку кубика — этот импортёр уже поддерживает новый набор.
  3. Нажми PLACE на появившемся мешке. Кубики можно бросать клавишей R.

Если импортёра ещё нет, скачай его объект и положи файл в Documents/My Games/Tabletop Simulator/Saves/Saved Objects. Затем открой Objects → Saved Objects в TTS.

Скачать импортёр TTS

«Скачать объект TTS» — такой же прямой импорт через Saved Objects. PNG можно импортировать вручную через Objects → Components → Custom → Custom Dice, выбрав D6.
