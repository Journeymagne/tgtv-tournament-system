Tabletop Simulator

Карты и жетоны по одной ссылке

Создайте снимок команды для TTS: колода карточек и мешочки с отдельными жетонами. Набор будет доступен каждому, у кого есть ссылка. Черновик не появится в библиотеке.

Ссылка сохраняет текущую версию. После правок создайте новую; старые наборы останутся прежними. Удаление команды удаляет и её ссылки TTS.

Локальная копия: ссылка работает в TTS на этом компьютере. Для игры с друзьями создайте ссылку на развёрнутом сайте.

Как установить импортёр — один раз
  1. В TTS создайте обычный блок через Objects → Components → Blocks.
  2. Нажмите «Копировать код импортёра» ниже.
  3. На блоке выберите ПКМ → Scripting → Scripting Editor. Вставьте код в скрипт этого блока и нажмите Save & Play.
  4. На блоке появится кнопка IMPORT TEAM. Нажмите её и вставьте ссылку на набор.
  5. На мешочке команды нажмите PLACE. В мешочке Tokens ещё раз нажмите PLACE, затем вытаскивайте копии из нужных мешочков. PACK собирает выложенные мешочки обратно.

Сохраните блок через ПКМ → Save Object. На другом столе он будет доступен в Objects → Saved Objects.

Скачать изображения колоды для ручного импорта

Все карты команды в одной колоде: PNG лиц и PNG оборотов. Продолжения правил находятся на оборотах.

В TTS один лист вмещает до 69 карт. Набор разделён только по этому лимиту: импортируйте каждую пару PNG и сложите колоды вместе на столе.

↓ Скачать ZIP

Как загрузить колоду

  1. Распакуйте ZIP. В TTS откройте Objects → Components → Custom → Deck.
  2. Выберите PNG лиц в Face, PNG оборотов в Back. Для игры с друзьями выберите Cloud при загрузке обоих изображений.
  3. Выставьте параметры ниже и нажмите Import.

Unique Backs: ON · Back is Hidden: OFF · Sideways: OFF

Оперативники повёрнуты на 90°, чтобы поместиться в ту же колоду без искажения. На столе поверните их для чтения.

Для колоды TTS принимает изображения PNG/JPG, а не многостраничный PDF.
