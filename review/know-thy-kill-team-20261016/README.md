# 200 добавленных вопросов — архив согласования

Все 200 вопросов добавлены в основной банк 22 октября 2026 по указанию пользователя. В банке теперь 300 вопросов, по 75 каждого уровня. Таблица сохранена для просмотра и замечаний; её чекбоксы больше не определяют включение вопросов в игровые сессии.

Откройте `Know-Thy-Kill-Team-200-review.html` в браузере. Он содержит все данные и оформление, работает без подключения к серверу и не изменяет текущий игровой банк.

- В каждой строке есть чекбокс **«Добавить»**, четыре варианта, правильный ответ, объяснение, ссылка на правило и поле замечания.
- Уровни содержат по 50 кандидатов: Рекрут `kt-101…150`, Боец `kt-151…200`, Ветеран `kt-201…250`, Эксперт `kt-251…300`.
- Фильтры, поиск и переключатель «Только выбранные» помогают просматривать набор. Кнопки массовой отметки работают со всеми найденными строками, включая другие страницы.
- **Скачать выбор JSON** сохраняет выбранные вопросы целиком, их ID и все замечания. Этот файл можно передать для последующего добавления одобренных вопросов.
- **Сохранить таблицу с отметками** создаёт автономную HTML-копию со встроенным выбором и замечаниями. Копию можно открыть на другом компьютере.
- **Загрузить выбор** восстанавливает JSON именно этого набора; перед заменой непустого выбора запрашивается подтверждение.
- **Скачать таблицу CSV** выгружает все найденные вопросы и отметки для просмотра в табличном редакторе.

Отметки сохраняются в localStorage этого браузера и не связаны с игровым прогрессом аккаунта. Для переноса используйте JSON или HTML. Если браузер запрещает локальное хранение, страница явно сообщает об этом и позволяет скачать текущий выбор.

Банк кандидатов — `candidates.json`, исходные файлы — `level-1.json`…`level-4.json`; источники и редакторская проверка описаны в соответствующих `level-*-sources.md`.

Для уровня 4 авторский исходник — `author-level-4.cjs`: после его изменения сначала запустите `node review/know-thy-kill-team-20261016/author-level-4.cjs`, чтобы обновить `level-4.json`.

Для пересборки автономного HTML после правки вопросов:

```powershell
node review/know-thy-kill-team-20261016/build-review.cjs
```

Сборка проверяет количество, структуру, уникальные ID и точные повторы относительно рабочего банка. Совпадение с уже добавленным вопросом допустимо только при полностью одинаковом содержимом. Сборка не изменяет `src/training-data/questions.json`. Семантическая сверка и проверка правил выполняются отдельно.

Для локального просмотра в Компаньоне сборка также создаёт `review.preview.html`. Его размещают как `public/training/review.html`, а `review.js` — как `public/training/review-ui.js`: внешний скрипт совместим с CSP приложения. Автономный файл для передачи пользователю — именно `Know-Thy-Kill-Team-200-review.html`.
