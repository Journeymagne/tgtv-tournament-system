04 / ПОВТОРНОЕ ИСПОЛЬЗОВАНИЕ

Подключить в новом сервисе

Для будущего использования скопируйте токены, стили и компоненты в новый сервис. Данные пользователя и обработчики действий передаются явно. Сейчас каталог работает автономно.

Минимальный шаблон
// После загрузки tokens.css, components.css и components.js:
const bar = KTComponents.accountBar({
  user: { name: 'Player', rating: 1123 },
  locale: 'ru', theme: 'dark',
  profileHref: '#profile', loginHref: '#login',
  onTheme: value => { /* тема будущего сервиса */ },
  onLocale: value => { /* язык будущего сервиса */ },
  onLogout: async () => { /* выход в будущем сервисе */ }
});
document.querySelector('[data-account-bar]').append(bar.element);
const bell = KTComponents.notificationButton({ count: 3 });
bar.notifications.append(bell.element);

Для отдельных элементов: KTComponents.button(), avatar(), rating(), notificationButton(), accountBar(). Исходный код компонентов.
