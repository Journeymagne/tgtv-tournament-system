  шрифт интерфейса и совместимые переменные Companion находятся рядом.
  Общее `[hidden]` заменяет повторные правила в компонентах и отдельных сервисах.
- В `public/studio/style.css` объединены прежние базовые стили и `theme.css`
  с сохранением порядка каскада. Более ранние свойства, перекрываемые поздним
  правилом того же селектора, удалены. Studio загружает один файл оформления.
  `theme.css` оставлен как импорт для совместимости со старыми страницами.
- Удалены пустой импорт `companion/css/variables.css` и повторное
  `justify-items` из мобильного правила профиля.
- Компактные файлы шапки, Studio, отзывов, обсуждений, кубиков и токенов
  записаны в читаемом формате. Размер исходников вырос из-за отступов;
  сокращение относится к числу правил и объявлений, а не к минификации.
- Обновлены маркеры кэша изменённых CSS и согласованы версии `styles.css`,
  `app.js` и SEO: `5.3.3-css-refactor`.
