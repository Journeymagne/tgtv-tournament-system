# Studio → Tabletop Simulator

В Studio откройте **Экспорт → Tabletop Simulator → Создать ссылку для TTS**.
Нужен обычный аккаунт портала. Публиковать команду в библиотеке не требуется.
Ссылка открывает снимок команды: одну общую колоду, карточки-справочники
жетонов и отдельные игровые жетоны. Миниатюры оперативников экспорт не создаёт.

## Установка импортёра

Один раз на столе TTS:

1. Создайте блок через **Objects → Components → Blocks**.
2. В окне экспорта Studio нажмите **Копировать код импортёра**.
3. На блоке откройте **ПКМ → Scripting → Scripting Editor**, вставьте код
   в скрипт именно этого блока и нажмите **Save & Play**.
4. Кнопка **IMPORT TEAM** на блоке предлагает вставить ссылку из Studio.
5. Сохраните блок через **ПКМ → Save Object**, чтобы использовать его на других столах.

Альтернатива: скачайте готовый объект по ссылке в том же окне. В Windows
положите файл в `Documents/My Games/Tabletop Simulator/Saves/Saved Objects`,
затем выберите **Objects → Saved Objects**. При перенаправлении Documents
в OneDrive используйте фактическую папку документов Windows.
Это единственная установка импортёра; отдельные JSON команд скачивать не нужно.

Импортёр привязан к сайту, с которого получен. Для локальной копии и рабочего
сайта нужны соответствующие импортёры. Локальная ссылка `127.0.0.1` пригодна
для просмотра на этом компьютере; другим игрокам нужны ссылки с доступного
им сайта. После выкладки создайте новый экспорт на рабочем сайте.

## На столе

- **PLACE** на мешке команды выкладывает колоду и мешок Tokens.
- **PLACE** на Tokens выкладывает контейнеры с бесконечным запасом каждого вида жетонов.
  Контейнер повторяет форму, цвет, символ и размер своего жетона.
- Вытаскивайте из них нужное количество копий. Варианты вроде `1, 2, 3`
  становятся тремя отдельными видами.
- **PACK** собирает объекты, выложенные соответствующим мешком, обратно.
  Жетоны-копии, разложенные на поле, остаются на месте; объекты в руке не забираются.
- Карточки оперативников лежат в общей колоде повёрнутыми на 90°;
  поверните их для чтения. Продолжения правил находятся на оборотах.

Круги по умолчанию имеют диаметр 20 мм, настраиваемый в Studio от 5 до 60 мм.
Lua жетона выставляет размер по фактическим границам загруженного объекта
в единицах стола TTS (1 единица = 1 дюйм). Для прочих форм задаётся размер
по большей стороне. Центральный символ и его масштаб совпадают с карточкой.

## Поведение в Kill Team UI

В редакторе каждого жетона доступно поле **Свойства жетона в TTS**:

| Режим | Назначение | Экспорт |
| --- | --- | --- |
| Аура расстояния — без прикрепления | Отдельный маркер на столе с кольцом дистанции; к моделям не прикрепляется | `KTUIToken`, `KTUIMarker`, `CustomToken.Stackable: false` |
| Прикрепление к модели | Эффект на совместимой модели KTUI без счётчика | `KTUIToken`, `KTUITokenSimple`, `CustomToken.Stackable: false` |
| Прикрепление к модели со счётчиком | Каждая следующая копия того же жетона увеличивает счётчик эффекта | `KTUIToken`, `KTUITokenSimple`, `CustomToken.Stackable: true` |

Совместимая модель сама обрабатывает жетон; Studio не меняет её характеристики
и не исполняет игровые правила. На столе без KTUI все жетоны остаются обычными
объектами. Идентификатор эффекта стабилен для проекта, жетона, номера варианта
и наличия счётчика. Старый режим «Маркер и эффект» в редакторе преобразуется
в прикрепление с сохранением настройки счётчика.

У маркеров есть **Дистанция маркера, дюймы**: 0–12, по умолчанию 1.
В TTS наведите курсор на вытащенный жетон и введите число: кольцо изменит
дистанцию и примет цвет игрока; 0 скрывает кольцо. В меню ПКМ доступны
готовые дистанции и **Default range** для возврата к значению из Studio,
в том числе дробному. Дистанция и цвет сохраняются вместе со столом.
Кольцо измеряется от края круглого жетона. У прочих форм базовый радиус
равен половине большей стороны. Эффекты оперативника кольца не рисуют;
их форма может быть любой, в том числе круглой.

Изменения требуют новой ссылки и повторного импорта. Уже стоящие на столе
объекты не обновляются. Проверка поведения в TTS выполняется вручную.

## Ссылки и хранение

Снимок неизменяемый: после правок создаётся новая ссылка. Предыдущая продолжает
показывать старую версию. Список **Мои ссылки на эту команду** доступен только
владельцу, там можно скопировать или удалить ссылку с одним подтверждением.
Удаление команды или аккаунта также удаляет соответствующие экспорты.

Каждый, у кого есть ссылка, может получить изображения. Ссылка не содержит
логин, сессию или токены авторизации. Публичного каталога экспортов нет.
Удаление прекращает выдачу набора и PNG с сервера, но не удаляет уже скачанные
копии или кэш TTS у других игроков. Не удаляйте используемые ссылки:
сохранённым столам могут потребоваться их картинки при следующей загрузке.

Лимиты: 690 карт, 300 видов жетонов, 64 МиБ изображений на снимок,
20 снимков одной команды и 512 МиБ на аккаунт. Многолистная колода автоматически
собирается в один `DeckCustom`. Прежняя выгрузка PNG/ZIP доступна в свёрнутом
разделе ручного импорта и не требует размещения изображений на сервере.

## Развёртывание

- Миграция **036_studio_tts_exports** добавляет таблицы снимков и PNG в PostgreSQL.
  Она применяется обычным стартом приложения. Включайте эти таблицы в резервную копию.
- `COMPANION_ORIGIN` / `SITE_URL` должны указывать на публичный HTTPS origin.
  В локальной копии оставьте их пустыми или укажите её адрес и порт.
- Для `POST /api/studio/tts/exports` нужен лимит reverse proxy **100m**;
  приложение допускает до 96 МиБ JSON с base64. Обычные API-лимиты не меняются.
- GET manifest, PNG и OBJ должны быть доступны без авторизации: их читает TTS.
  Запись, список и удаление требуют сессии владельца; запись — также CSRF
  и проверки активного аккаунта Studio.
- Принимаются только декларативный манифест и проверенные PNG. Объекты,
  адреса изображений и Lua формирует сервер из собственных шаблонов.
  Переданный клиентом Lua или произвольный TTS JSON не исполняется.
- OBJ контейнеров генерируются сервером из четырёх разрешённых форм.
  Внешние модели и скрипты автообновления для жетонов не используются.

Исходники: `public/studio/tts-share.js`, `public/studio/tts-export.js`,
`src/api/studio-tts.js`, `src/domain/studio-tts-*.js`, `src/tts/*.lua`.

Справка: [TTS external editor](https://api.tabletopsimulator.com/externaleditorapi/),
