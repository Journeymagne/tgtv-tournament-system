# Search appearance

The Companion homepage uses WebSite and ItemList microdata for its visible brand
and eight linked tools. Public tournament pages include a visible BreadcrumbList
outside the client application mount so navigation survives app initialization.
Tournament events use SportsEvent and only valid EventStatusType values.

The Companion HTTP adapter provides the shooting calculator description,
canonical and sharing metadata in the initial HTML at /combat; React retains
control of subsequent calculator navigation. The standalone ktcalc source is
unchanged, and creator attribution is retained.

Yandex Webmaster: select "No region" for this international online project.
That setting must be made by the owner in the verified Webmaster account.
Sitelinks are selected automatically by Yandex; the homepage supplies ordinary
crawlable links and clear section names. Business listings, medical/education
features and partner answer programmes are not enabled for this project.
