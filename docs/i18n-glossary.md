# Глоссарий локализации

Политика системных переводов утверждена пользователем 16 ноября 2026 года.
Канонические списки: `public/i18n/glossary.js`. Проверки словарей:
`test/unit/i18n.test.js`. Эта политика заменяет прежнее требование сохранять
общие подписи Killzone, Kill Team и Roll-off на английском.

## Английские игровые термины

Primary Op, Crit Op, Kill Op, Tac Op, Turning Point, Counteract, Re-roll,
Strategic Ploys, Firefight Ploys, Equipment, Wounds и Expended сохраняются
по-английски. Order и Ready также сохраняются как термины правил — например,
«оперативник со статусом Ready», «Order Engage».

Обычные интерфейсные значения не затрагиваются: порядок сортировки, статус
готовности турнира и кнопка «Сохранить» остаются русскими. Перевод Save как
«сейв» относится только к игровому броску. «Ранение» как состояние Injured
не заменяет название характеристики Wounds.

## Русские подписи

| Термин | Подпись |
| --- | --- |
| Killzone | Киллзона |
| Kill Team — игровой отряд | Киллтим |
| Victory Points | Победные очки; сокращение VP сохраняется |
| Roll-off | Бросок |
| Layout | Раскладка |
| Deployment | Расстановка |
| Mission / Faction / Operative | Миссия / Фракция / Оперативник |
| Activation / Initiative | Активация / Инициатива |
| Weapon / Weapon profile / Weapon rules | Оружие / Профиль оружия / Правила оружия |
| Ability / Action | Способность / Действие |
| Shooting / Fighting / Melee | Стрельба / Бой / Ближний бой |
| Strike / Parry | Удар / Парирование |
| Normal damage / Critical damage | Обычный урон / Критический урон |
| Hit / Save | Попадание / Сейв |
| Cover / Terrain / Visibility | Укрытие / Террейн / Видимость |
| Token / Marker | Жетон / Маркер |

Склонение русских подписей зависит от предложения: «Без киллзоны»,
«Выберите киллтим», «Победитель броска». Crit Op не обозначается «Миссия»:
этот термин остаётся у всего набора условий игры, а не отдельного поля Crit Op.
Layout и Deployment имеют разные подписи даже при числовых значениях 1–6.

## Имена и данные

Названия игры Kill Team / Warhammer 40k Kill Team, продуктов и функций
(Tabletop Simulator, All Kill Team Challenge, Classified и Non-Classified),
именованные Kill Teams, Tac Ops, Crit Ops, Killzones и сезоны не переводятся.
Подпись «Киллзона» не меняет значения Volkus или Gallowdark. Подпись «Киллтим»
не меняет название команды, путь к её логотипу или ключ статистики.

APL, AP, CP, VP, Approved Ops, Dataslate, Engage и Conceal сохраняются.
Strength of Schedule / SoS остаются английскими по ранее согласованной политике.
`IRL` в русской подписи переводится как «Вживую».

Редакторские тексты FAQ, вопросы и сохранённые ответы тренажёра, исходные правила
и пользовательские карточки не являются словарями интерфейса. Их идентификаторы,
значения и версии не переписываются при изменении системных подписей.

## Остальные соглашения

Турнирные термины 31–36 из предварительного аудита этим решением не меняются.
Существительное Challenge остаётся «челлендж», глагол кнопки — «Вызвать».
В составе имени All Kill Team Challenge ничего не переводится.

## Проверка

Существующие проверки контролируют паритет ключей и плейсхолдеров RU/EN,
защищённые английские имена, запрещённые варианты, HTML-безопасность и причины
совпадающих переводов. `CONTEXTUAL_RULES_TERMS` описывает игровые Order/Ready:
их нельзя применять как запрет перевода одноимённых обычных интерфейсных слов.
