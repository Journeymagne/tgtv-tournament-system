В командном формате 3×3 встречаются две команды по три игрока. Перед играми капитаны определяют, кто с кем сыграет, на каких столах и с какими миссиями. Этот процесс называется парингом. Здесь используется адаптация WTC для трёх игроков в команде, поэтому порядок отличается от официального формата 5×5.

## С кем встречается команда

Один из трёх игроков команды становится капитаном и представляет её на парингах. В турнире участвует чётное число команд — от 4 до 128, поэтому в каждом раунде у каждой команды есть соперник.

В первом раунде команды из верхней половины посева встречаются с командами из нижней. Дальше соперники определяются по текущей командной таблице. Повторных встреч стараются избегать, когда это возможно; окончательные пары утверждает организатор.

На каждый раунд подготовлены три стола: три разные Killzones, каждая со своей расстановкой от 1 до 6. Набор одинаков для всех командных встреч этого раунда. В следующем раунде он может измениться.

## Ролл-офф и баны миссий

Паринг начинается с броска D6 у каждого капитана. При равенстве капитаны перебрасывают кубики. Победитель получает роль **Attacker**, а проигравший — **Defender**. Эти роли определяют очерёдность выбора на следующих этапах.

На все три индивидуальных паринга одной командной встречи используется общий пул из девяти Crit Ops: Secure, Loot, Transmission, Orb, Stake Claim, Energy Cells, Download, Data и Reboot. Сначала Defender банит одну миссию, затем Attacker — ещё одну. Из оставшихся семи миссий капитаны выбирают по одной для каждой пары. Выбранная миссия исключается из общего пула: повторно назначить её другой паре в этой же командной встрече нельзя.

## Как определяются соперники: Shield и Sword

Сначала каждый капитан тайно выбирает одного игрока своей команды — **Shield**. Оба выбора раскрываются вместе, когда оба капитана их подтвердили.

Два остальных игрока каждой команды — **Swords (мечи)**. После раскрытия Shield капитан команды, которой принадлежит Shield, выбирает ему соперника из двух Swords другой команды. Оба выбора остаются скрытыми, пока оба капитана их не подтвердят.

Так образуются три пары:

- Shield команды A играет против одного из Swords команды B, выбранного капитаном A.
- Shield команды B играет против одного из Swords команды A, выбранного капитаном B.
- Два оставшихся Swords встречаются друг с другом.

## Как распределяются столы и миссии

Когда соперники известны, капитаны распределяют между ними три подготовленных стола и выбирают миссии. Порядок одинаков для игр в TTS и за реальным столом. Роли Attacker и Defender сохраняются с начального ролл-оффа.

| Шаг | Кто выбирает | Что получает пара |
| --- | --- | --- |
| 1 | Attacker | Стол для игры Shield команды Defender |
| 2 | Defender | Миссию для этой игры |
| 3 | Defender | Один из двух оставшихся столов для игры Shield команды Attacker |
| 4 | Attacker | Одну из оставшихся доступных миссий для этой игры |
| 5 | Defender | Одну из оставшихся доступных миссий для третьей пары |

После выбора второго стола третья пара получает оставшийся стол автоматически. Расстановка уже закреплена за столом. Каждая миссия используется только один раз: в итоге три пары играют на трёх разных столах с тремя разными миссиями, а четыре миссии остаются невостребованными.

## После паринга

У каждой пары теперь есть соперник, Killzone, расстановка и Crit Op — всё готово к игре. В TTS внесённый результат становится окончательным после подтверждения вторым игроком. В очном формате результат сохраняется сразу. При ошибке с исправлением может помочь администратор.

Командные турнирные очки начисляются, когда закончены все три игры встречи. После завершения всех командных встреч раунда организатор открывает следующий. По окончании последнего раунда публикуются итоги турнира.
