## WTC · 3×3

1. Оба капитана бросают D6; при равенстве перебрасывают. Победитель — Attacker, проигравший — Defender.

2. Общий пул встречи — девять миссий. Defender банит одну миссию, затем Attacker — другую. Остаётся семь.

3. Оба капитана тайно выбирают Shield из своей команды. Выбор раскрывается после подтверждения обоими капитанами.

4. Каждый капитан тайно выбирает своему Shield соперника из двух Swords другой команды. После обоих подтверждений выборы раскрываются. Два оставшихся Swords образуют третью пару.

5. Пара Shield Defender: Attacker выбирает один из трёх столов, Defender — миссию из оставшегося пула.

6. Пара Shield Attacker: Defender выбирает один из двух оставшихся столов, Attacker — другую доступную миссию.

7. Оставшиеся Swords получают третий стол автоматически. Defender выбирает им ещё одну доступную миссию. Все три стола и три миссии разные; расстановка закреплена за столом.

8. Паринг завершён: созданы три личные игры. В TTS используются три общих виртуальных стола раунда, в IRL — отдельная линия столов встречи.

## Sword Shield Classic · 3×3

1. Определите инициативу кубовкой или другим согласованным способом и укажите победившего капитана в приложении. Банов миссий нет: используется пул миссий раунда.

2. Оба капитана тайно выбирают Shield из своей команды. Выбор раскрывается после подтверждения обоими капитанами.

3. Каждый капитан тайно выбирает своему Shield соперника из двух Swords другой команды. После обоих подтверждений выборы раскрываются. Два оставшихся Swords образуют третью пару.

4. Капитан с инициативой выбирает стол ИЛИ миссию для своего Shield. Второй капитан назначает этой паре оставшийся параметр: миссию либо стол.

5. Капитан без инициативы выбирает стол ИЛИ миссию для своего Shield. Капитан с инициативой назначает этой паре оставшийся параметр.

6. Оставшиеся Swords получают свободный стол. Если миссий в пуле ровно три, последняя назначается автоматически; если больше — миссию выбирает капитан без инициативы.

7. Все пары получают разные столы и миссии. Расстановка закреплена за столом. После всех назначений создаются три личные игры.

## Doubles · 2×2

1. Бросьте D6 вне приложения; при равенстве повторите. Победитель выбирает право составить пары или распределить столы. Проигравший получает другое право.

2. Капитан с правом составления пар определяет два личных матчапа. Другой капитан распределяет между ними два стола линии встречи.

3. Проигравший ролл-офф выбирает одну из четырёх миссий раунда на любой стол. Победитель выбирает одну из оставшихся трёх на второй стол.

4. Внесите обе пары, разные столы и разные миссии в ручную форму. Каждый игрок участвует один раз. Для перестановки сначала освободите нужный выбор.

5. Любой капитан или организатор сохраняет обе пары. Создаются две личные игры. Shield/Sword и баны в этом формате не используются.

## Ручное назначение · 3×3

1. Пошаговый капитанский паринг выключен. Капитаны согласовывают три пары, столы и миссии вне приложения; этапов инициативы, банов и скрытого выбора в интерфейсе нет.

2. Капитан или организатор указывает в форме по одному игроку каждой команды для каждой из трёх игр. Каждый игрок участвует ровно один раз.

3. Назначьте каждой паре отдельный стол и отдельную миссию из доступного пула. Расстановка закреплена за столом.

4. Проверьте все назначения и сохраните три пары — приложение создаст личные игры.

## WTC · прежние правила · TTS

1. Эта встреча сохранена по прежней версии правил. Капитаны выполняют ролл-офф; победитель — Attacker, проигравший — Defender. Этапа банов нет.

2. Оба капитана тайно выбирают Shield из своей команды. Выбор раскрывается после подтверждения обоими капитанами.

3. Каждый капитан тайно выбирает своему Shield соперника из двух Swords другой команды. После обоих подтверждений выборы раскрываются. Два оставшихся Swords образуют третью пару.

4. Attacker выбирает миссию для Shield Defender, затем Defender — для Shield Attacker. Третья пара получает оставшуюся миссию автоматически. Используйте сохранённые окружения встречи.

## WTC · прежние правила · IRL

1. Эта встреча сохранена по прежней версии правил. Капитаны выполняют ролл-офф; победитель — Attacker, проигравший — Defender. Этапа банов нет.

2. Оба капитана тайно выбирают Shield из своей команды. Выбор раскрывается после подтверждения обоими капитанами.

3. Каждый капитан тайно выбирает своему Shield соперника из двух Swords другой команды. После обоих подтверждений выборы раскрываются. Два оставшихся Swords образуют третью пару.

4. Defender выбирает стол для своего Shield, Attacker — миссию этой паре. Затем Attacker выбирает стол для своего Shield, Defender — миссию. Третья пара получает оставшиеся стол и миссию автоматически.
