## Настройки печати

Для готовой раскладки A4 выберите альбомную ориентацию, масштаб **100%** и одну страницу PDF на листе. Повторно включать «две страницы на лист» не нужно. Центральный пунктир — линия разреза.

Версия A5 подходит для отдельной печати или собственной раскладки.
