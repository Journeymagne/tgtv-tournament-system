# Handouts

**English-language** terrain references for WTC Open, Volkus, Tomb World, WTC Into the Dark and Octarius. Includes keywords, movement, Guard, terrain illustrations and separately labelled community FAQ rulings.

## Print settings

For the imposed A4 file, select landscape orientation, **100% scale**, and one PDF page per sheet. Do not select two pages per sheet again. The centre dashed line is the cutting guide.

Use the A5 file for individual printing or your own page arrangement.
