# Сезоны турниров и статистики

Новый одиночный или командный турнир по умолчанию получает последний актуальный
сезон из `public/game-data.js`. Форма создания и сервер используют один справочник
и одно правило выбора по датам начала и окончания. Будущий сезон не выбирается
до его начала; если даты сезонов пересекаются, выбирается начавшийся позднее.

Супер-администратор меняет сезон через **Администрирование → Турниры → нужный
турнир → Настройки → Сезон**. Поле доступно и у активного, и у завершённого
турнира. Выбор сохраняется автоматически; кнопка сохранения также доступна.
Обычный администратор, организатор или судья не может изменить сезон уже
созданного турнира. При создании можно явно выбрать сезон вместо предложенного.

Вся история одиночных и командных игр турнира учитывается в статистике выбранного
сезона, независимо от даты матча. После изменения игры перестают учитываться в
прежнем сезоне и появляются в выбранном. Счёт, очки, пары, даты, рейтинг и
опубликованные итоговые места сохраняются. Пересоздавать игры и пересчитывать
рейтинг для смены сезона не требуется.

Сезон хранится у турнира. API истории игр получает его из связанного турнира,
а общая статистика использует это значение для обоих типов турнирных игр.
Обычные игры вне турниров по-прежнему относятся к сезону по дате результата.

Смена выполняется транзакционно и записывается в журнал турнира. Неизвестный
сезон или подтверждение на основе устаревших настроек отклоняются. Доступ к
прочим настройкам завершённого турнира остаётся закрытым. Новые зависимости,
миграции базы данных и переменные окружения не требуются.
