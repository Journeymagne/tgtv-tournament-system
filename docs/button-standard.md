# Единый размер кнопок

Эталон — прежняя кнопка Back. Размеры задаются в `:root` файла `public/styles.css`:

- высота одной строки — 40 px (`--button-height`);
- текст — 16 px, насыщенность 900, межстрочный интервал 1;
- отступы — 2 px сверху, 14 px по бокам, 0 снизу;
- скругление — 7 px;
- ширина определяется подписью и раскладкой контейнера;
- длинная подпись может переноситься на узком экране без обрезки.

Базовый размер применяется ко всем новым `<button>`, ссылкам с классами
`primary-button`, `ghost-button`, `danger-button`, `small-button` и кнопкам
выбора файлов. `small-button` сохранён как совместимое имя оформления:
его размер теперь совпадает с остальными вариантами. Цветовые классы
не должны менять высоту, отступы, размер или насыщенность текста.

Кнопки с одной иконкой используют квадрат 40 × 40 px. Вкладки, навигация,
действия редакторов и документации используют тот же базовый размер.
У кнопок внутри полей ввода сохраняется соединение с соседним полем.

Кликабельные имена и ссылки, сортировка заголовков таблиц, содержательные
карточки и подложка закрытия меню имеют отдельную роль в интерфейсе:
для них предусмотрено явное оформление по размеру содержимого.

При добавлении действий использовать существующие цветовые классы,
а их размещение задавать контейнером (`row-actions`, сеткой или flex).
Не добавлять локальные `font-size`, `height` и `padding` для отдельной
кнопки — общий размер меняется через `--button-*`.
