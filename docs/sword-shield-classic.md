# SWORD SHIELD CLASSIC и линии командных турниров

Формат для составов по три игрока. Победитель командного матча определяется количеством индивидуальных побед, включая ничью при равенстве. Командные очки: 2/1/0. ГП не рассчитываются. WTC сохраняет ГП, кубовку, баны и свой порядок распределения условий.

## Подготовка раунда

После закрытия регистрации организатор открывает генерацию раунда. Для каждого играющего матчапа предлагается отдельная линия из трёх столов; состав линий переносится из предыдущего раунда. Номера столов, киллзоны и раскладки редактируются. Линии можно переназначить матчапам до сохранения и запуска. Стол и линия не могут использоваться одновременно в двух матчах.

Для Classic организатор задаёт три разные миссии один раз на весь раунд. Отдельных наборов миссий для линий нет. Столы и миссии распределяются независимо капитанами. До старта нужны полные составы, линии с настроенными столами и три миссии. Подготовленный первый раунд можно повторно открыть и изменить до старта турнира.

В ТТС требуется подготовить три виртуальных стола на линию и передать доступ к лобби. В ИРЛ — обозначить линии и столы, расставить террейн и подготовить маркеры. Каждый стол должен поддерживать любую миссию раунда. Карточки с названием команды на рубашке и ником/фракцией на лицевой стороне нужны только при паринге вне приложения.

## Капитанский паринг

1. Записать команду, получившую инициативу вне приложения.
2. Обоим капитанам скрытно подтвердить своего щита.
3. Обоим скрытно выбрать меч противника в соперники своему щиту.
4. Раскрыть три пары; оставшиеся мечи играют между собой.
5. Капитан с инициативой выбирает стол либо миссию для своего щита. Второй капитан дополняет оставшийся параметр.
6. Для другого щита капитаны меняются ролями.
7. Оставшиеся стол и миссия назначаются третьей паре автоматически. Создаются обычные игры с внесением результатов.

## Ручной режим и зачёт

Переключатель пошагового паринга доступен при создании и в настройках турнира. Выключение открывает форму трёх пар, столов и миссий без этапов щитов и инициативы. Изменение применяется только к ещё не начатым парингам; начатые сохраняют свой режим. Действуют прежние права капитанов и организаторов. Сохранение всех пар атомарное.

Тайбрейкеры можно включать и задавать в любом порядке: тотал побед игроков, разница ВП, тотал ВП. Основной показатель — командные очки. Учитываются только завершённые индивидуальные игры. Отключение пользовательского порядка сохраняет прежнюю сортировку (победы игроков, ВП, Tac Op); явно пустой пользовательский порядок оставляет сравнение по командным очкам и стабильному посеву. Исправление результатов пересчитывает показатели.
