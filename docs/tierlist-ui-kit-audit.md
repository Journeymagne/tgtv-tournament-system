# Проверка UI Kit: тирлисты

Дата: 11 ноября 2026. Эталон — [UI Kit](ui-kit.md), [стандарт кнопок](button-standard.md) и общие `public/companion-tokens.css`, `companion-shell.css`.

Проверен локальный редактор `/tierlist` в Chrome на экранах 1440 × 1000 и 390 × 844, в светлой и тёмной темах. Запущены отдельные gateway/accounts/tierlists процессы с собственными PostgreSQL-ролями; база предпросмотра изолирована от пользовательских данных. Основной предпросмотр использует обычную сессию локального администратора. Гостевой режим проверен через отдельный локальный gateway без автоматического входа.

| Элемент | Наблюдение | Результат |
| --- | --- | --- |
| Общая шапка | Companion logo, профиль, MMR, язык, тема, выход и уведомления из общего shell | Соответствует |
| Основные действия | Высота 40 px, на телефоне 44 px; шрифт 14 px / 650, радиус 7 px | Соответствует |
| Основное действие | Тёмный текст `rgb(5,5,5)`; оранжевый фон из `--accent` в обеих темах | Соответствует |
| Вторичные действия | `--panel-2`, `--ink`, `--line-strong`; без объёмных теней | Соответствует |
| Поля и фокус | Общие цвета; минимальная высота действия; CSS focus-visible 2 px + отступ 3 px | Соответствует |
| Адаптивность | Нет горизонтального переполнения при 1440 и 390 px; поля и действия переносятся | Соответствует |
| Изображения | 48 локальных прозрачных PNG, `object-fit:contain`, все загрузились | Соответствует |
| Язык | Заголовок, действия и подсказки переключаются RU/EN через общие настройки | Соответствует |
| Игровые элементы | S/A/B/C/F и миниатюры имеют собственные размеры по роли; стандарт кнопок действий к ним не применяется | Допустимо |

Снимки экрана: [desktop dark](../design/ui-kit/audit/2026-11-11-tierlist/desktop-dark.png), [desktop light](../design/ui-kit/audit/2026-11-11-tierlist/desktop-light.png), [mobile dark](../design/ui-kit/audit/2026-11-11-tierlist/mobile-dark.png), [mobile light](../design/ui-kit/audit/2026-11-11-tierlist/mobile-light.png).

При проверке исправлена остававшаяся после загрузки надпись «Загрузка каталога…». После исправления необработанных ошибок JavaScript не обнаружено.

Дополнительно пройден пользовательский сценарий: переход из главного меню, выбор исторического сезона, перемещение команд клавиатурой и нажатием, сохранение в профиль, перезагрузка, фильтр библиотеки по сезону и повторное открытие. Гостевой черновик восстанавливается после перезагрузки; действие предлагает вход для сохранения. Проверены ответы API: создание 201, обновление 200, устаревшая ревизия 409, отсутствие входа 401, чужой список 404, неверный CSRF 403.

Это визуальная проверка и проверка доступности/поведения локального предпросмотра. Автоматический набор тестов запускается только в GitHub Actions согласно AGENTS.md; production в рамках проверки не менялся.
