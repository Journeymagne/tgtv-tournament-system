# Паринги командного турнира 3×3

Правила приложения, согласованные 5 сентября 2026 года и обновлённые 6 сентября в части столов каждого раунда. Это адаптация для 3×3, а не буквальное воспроизведение WTC 5×5.

## До первого раунда

Организатор при старте турнира задаёт три разные Killzones и по одной расстановке (1–6) для каждой как начальные значения. При генерации **каждого** раунда он может изменить все три карты и расстановки. Форма предлагает значения предыдущего раунда (для первого — выбранные при старте); их можно оставить или заменить.

Три стола одинаковы для всех командных встреч **данного раунда**. Расстановка закреплена за столом. Выбранный набор сохраняется отдельно в раунде: следующие раунды не меняют карты, расстановки, назначения или результаты предыдущих. В TTS это виртуальные столы. Базовые записи столов остаются закрытыми от обычного редактирования после старта; новый набор задаётся только в форме генерации раунда.

При генерации раунда организатор проверяет командные пары, но не выбирает Crit Ops. Каждая встреча независимо получает девять миссий: Secure, Loot, Transmission, Orb, Stake Claim, Energy Cells, Download, Data, Reboot.

## Ролл-офф и баны

1. Каждый капитан нажимает «Бросить D6». Сервер бросает отдельный кубик для каждой стороны; значения видны обоим капитанам и зрителям.
2. При ничьей оба бросают снова, история бросков сохраняется.
3. Победитель автоматически становится Attacker, проигравший — Defender. Выбора роли нет.
4. Defender банит одну Crit Op, затем Attacker банит одну другую. Всего два бана, остаётся семь миссий. Баны действуют только внутри этой командной встречи.

## Скрытые Shield/Sword

1. Оба капитана независимо выбирают Shield из своей тройки. До подтверждения обоих чужой выбор скрыт.
2. После раскрытия Shield каждый капитан выбирает Sword из двух оставшихся игроков противника — соперника своему Shield. Эти выборы также раскрываются только после подтверждения обоих.
3. Формируются три игры: Shield команды A против выбранного ею Sword команды B; Shield команды B против выбранного ею Sword команды A; оставшиеся игроки друг против друга.

## Столы и миссии

Здесь Attacker и Defender означают исходные роли после ролл-оффа. Во второй Shield-игре они меняются местами при выборе окружения.

| Шаг | Кто выбирает | Что назначается |
| --- | --- | --- |
| 1 | Attacker | Стол для игры Shield исходного Defender |
| 2 | Defender | Одна из семи миссий для этой игры |
| 3 | Defender | Один из двух оставшихся столов для игры Shield исходного Attacker |
| 4 | Attacker | Другая доступная миссия для этой игры |
| 5 | Исходный Defender | Третья отличающаяся миссия для оставшейся пары |

Оставшаяся пара автоматически получает третий стол сразу после шага 3. В итоге используются три стола и три разные миссии; четыре незабаненные миссии остаются неиспользованными.

Выбор миссии для третьей пары исходным Defender — принятое допущение для адаптации 3×3 при оставшихся семи миссиях.

## Видимость и сохранение

Броски, роли, баны и каждое назначение стола/миссии публичны. Страницы паринга и публичного турнира обновляются каждые пять секунд, не сбрасывая незавершённый выбор в форме. Скрываются только неподтверждённые обеими сторонами Shield/Sword (администратор сохраняет существующий доступ к ним).

Три индивидуальные игры создаются после всех назначений. Killzone, расстановка и Crit Op сохраняются в каждой игре и не изменяются через форму её результата. Для TTS сохраняется подтверждение результата вторым игроком; для IRL — немедленное сохранение.

Новые правила применяются к новым раундам. Миграция не меняет уже существующие паринги и результаты: они сохраняют прежнюю версию правил. Для уже начатого турнира без настроенных общих столов организатор задаёт их при генерации первого раунда по новым правилам.

## WTC-очки и промежуточные результаты

Каждая завершённая игра даёт GP по формуле `10 + (VP игрока − VP соперника)`, с ограничением 0–20. Итоговые VP включают бонус Primary. Сумма GP двух игроков всегда равна 20.

Для встречи 3×3 принят диапазон ничьей **28–32 GP включительно** (отклонение ±2). После всех трёх игр команда получает 0 турнирных очков за 0–27 GP, 1 за 28–32 GP, 2 за 33–60 GP. Победа в двух личных играх сама по себе не определяет итог встречи.

Личных тайбрейков нет: равные VP означают ничью и 10:10 GP. Форма результата не предлагает тайбрейки; сервер запрещает их включение.

При равенстве турнирных очков команды сортируются по сумме личных побед, затем по сумме всех набранных VP, затем по сумме Tac Op VP. GP не являются критерием сортировки. Tac Op VP — сумма поля Tac Op у всех игроков во всех завершённых играх; отдельный бонус Primary сюда не прибавляется. При полном равенстве сохраняются исходный сид и затем ID состава.

После каждой завершённой игры её VP и GP сразу учитываются в текущем счёте. Личные победы, VP и Tac Op VP обновляются и до окончания командной встречи; турнирные очки — только после всех трёх игр. Для TTS неподтверждённые результаты показываются отдельным статусом и не входят в GP. Не сыгранные игры тоже помечаются отдельно.

Открыть паринг и смотреть обновления можно без входа по ссылке `/#/team-matches/<ID>`. Изменять результаты и выборы по-прежнему могут только уполномоченные участники/администраторы. MMR остаётся отдельным расчётом.

## Управление администратором

Администратор может открыть любой паринг, не будучи капитаном. В активном турнире ему доступны два подписанных блока управления: за команду A и за команду B. Через них выполняются броски D6, баны, выбор Shield/Sword, столов и миссий. Очерёдность и проверки допустимости сохраняются; действия фиксируются в аудите от имени администратора, а не капитана.

До завершения текущего этапа администратор может исправить уже подтверждённый Shield/Sword. Для изменения более ранних этапов из паринга доступен сброс до выбранного этапа; на этапе назначения окружения доступны ручные пары игроков. Сброс требует подтверждения: созданные личные игры и их результаты удаляются, рейтинги пересчитываются, раунд снова становится активным. Вход в паринг и просмотр результатов сами по себе ничего не меняют.
