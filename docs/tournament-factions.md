# Количество фракций на игрока

При создании турнира организатор выбирает **Количество фракций**: 1, 2 или 3.
Это максимум на одного игрока, а не требуемое количество. При лимите 2 или 3
можно зарегистрировать только одну фракцию и играть на ней весь турнир.
Дополнительные поля необязательны. Повторять одну фракцию в списке нельзя.

Настройка доступна для соло (Swiss и single elimination), WTC и SWORD SHIELD
CLASSIC в TTS и IRL, а также IRL Doubles; с капитанским парингом и ручным назначением пар.
В командном турнире каждый игрок ростера указывает свой список.

В отчёте турнира с несколькими разрешёнными фракциями игрок или администратор
выбирает одну из фракций, зарегистрированных соответствующим игроком.
Сервер проверяет выбор. Выбранная фракция сохраняется в результате конкретного
матча и используется в статистике игр. Список регистрации сохраняется отдельно;
статистика выбора фракций учитывает все зарегистрированные фракции.

До начала первого раунда дополнительные фракции скрываются по тем же правилам,
что и основная. Организатор может редактировать список в карточке участника или
ростера. Уменьшить лимит ниже уже зарегистрированного количества нельзя;
после начала турнира настройка количества блокируется.

API использует `factionCount` для турнира и `factions: string[]` для участника
или игрока ростера. Старые запросы с `faction` продолжают работать. Первая
фракция также доступна в прежних полях `faction` / `factionSnapshot`.
В отчёте передаётся одна фракция: `scores[resultKey].faction`.
Администратор по-прежнему может оставить фракции приглашённого соло-участника
или пустого командного прокси незаполненными; для них сохраняется выбор
фракции из общего списка в отчёте.

Миграция **053_tournament_factions** добавляет настройку и списки регистрации.
Для существующих турниров остаётся лимит 1, а ранее выбранная фракция
переносится в список. Миграция выполняется автоматически при запуске.
