# Kill Team Challenge: порядок зачёта

- Порядок обоих треков задаётся в `src/domain/kill-teams.js`. Интерфейс показывает серверный порядок без перестановок и самостоятельного пересчёта.
- Прогресс вычисляется из подтверждённых побед и ручных зачётов в хронологическом порядке. Учитывается только текущая команда трека; более ранняя победа следующей командой не копится на будущее.
- Classified и All Kill Team проходят независимо. Одна победа может продвинуть оба трека, только если эта команда сейчас доступна в каждом из них.
- Wildcards по-прежнему можно закрывать в любое время. Поражения, ничьи, неподтверждённые результаты и игры с `challengeCredit: false` не продвигают трек.
- Администратор может зачесть только текущую команду или wildcard. Проверка выполняется на сервере под блокировкой пользователя.
- Снятие зачёта шага сбрасывает и последующие зависимые шаги. Wildcards при этом сохраняются; интерфейс предупреждает перед снятием.
- Существующая история пересчитывается по этим же правилам при чтении, без удаления игр или записей ручного зачёта.
