# Know Thy Kill Team — банк вопросов

С миграции `062_training_moderation` этот JSON служит исходным набором для
каталога PostgreSQL. Рабочие статусы, правки и комментарии сохраняются в базе;
повторный запуск приложения не перезаписывает решения администраторов.
`kt-083` и `kt-086` отправлены на модерацию по обращению пользователя.
Вопросы на проверке не выдаются в сессиях; удалённые также исключаются из
требований к рангу. История ответов хранит исходные версии вопросов.

Версия `2026-10-22.1`: 300 вопросов, по 75 каждой сложности. Первые 100
(`kt-001`…`kt-100`) сохранены без изменений. Все 200 вопросов набора
[`candidates.json`](../../review/know-thy-kill-team-20261016/candidates.json)
(`kt-101`…`kt-300`) включены по указанию пользователя.

Источники первых 100 вопросов описаны в [foundation-sources.md](foundation-sources.md)
и [advanced-sources.md](advanced-sources.md), проверка — 15 октября 2026.
Для дополнительных вопросов проверка выполнена 16 октября 2026:
[уровень 1](../../review/know-thy-kill-team-20261016/level-1-sources.md),
[уровень 2](../../review/know-thy-kill-team-20261016/level-2-sources.md),
[уровень 3](../../review/know-thy-kill-team-20261016/level-3-sources.md),
[уровень 4](../../review/know-thy-kill-team-20261016/level-4-sources.md).
Добавление в банк не означает повторную проверку правил на дату выпуска.

За первый и второй верный ответ начисляется `сложность × 10 XP`.
Последующие ответы не увеличивают опыт. Максимум текущей базы — 15 000 XP.

| Ранг | XP |
| --- | ---: |
| Нубик | 0 |
| Фрешблад | 600 |
| Середняк | 2 400 |
| Знаток киллтима | 5 400 |
| Потнич | 9 600 |
| Судья | 15 000 |

Пороги выводятся из максимума базы: 0%, 4%, 16%, 36%, 64%, 100%.
«Судья» достижим только после двух верных ответов на каждый вопрос.
Прежний опыт сохраняется; текущий ранг пересчитывается по расширенной базе.
Аккаунты и гости используют один калькулятор прогрессии; ачивка получает те же данные.

Версия `2026-10-15.1` совместима с новой: обновление только добавляет вопросы,
не меняя старых ID, вариантов и индексов правильных ответов. Сервер принимает
ответы в прежних активных сессиях; гостевой клиент сохраняет статистику,
историю и незавершённую сессию при обновлении банка. При будущих изменениях
старых вопросов совместимость следует пересмотреть, а не добавлять версии автоматически.
