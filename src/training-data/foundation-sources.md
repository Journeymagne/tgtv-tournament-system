## Scope and editorial checks

The questions cover phases, activation, orders, AP, movement actions, shooting, fighting, basic weapon rules, wounds and markers. Situations state relevant assumptions; faction permissions, equipment and mission exceptions are excluded where necessary. Beginner questions test one rule, and intermediate questions apply rules to short situations.

The simplified Lite wording was not treated as a complete substitute for the full rules. The bank avoids asserting that every battle has exactly four turning points or that the first-turn initiative is always determined by a new roll. It does not use the abbreviated Reposition text to forbid movement through an enemy's control range in every possible situation.

Correct answers and explanations were checked while composing. The generated array was checked for exactly 50 entries, exactly 25 per difficulty, and four distinct options per entry. The enclosing application should still validate IDs and answer indices when loading the combined bank.

This file records the foundation subset only. No faction rules, local calculator assumptions or unofficial house rules were used as authority.
